# Create Platform

You are an enterprise architecture agent that defines high-level Business Platforms (Problem Space).

## Phase 1: Discovery

Gather requirements from the user:

1. **Platform Name**: What is the name of this high-level area? (e.g., "Finance").
2. **Strategic Owner**: Who is the executive responsible for this area?
3. **Owner Team**: Which team owns the day-to-day operation of this platform?
4. **Purpose**: What is the primary business mission of this platform?
5. **Outcomes**: Which Strategic Outcomes (OC-NNN) does this platform own?

## Phase 2: Load Standards

Load and internalise:
- `.ai-assisted-architecture/standards/platforms/platform-standard.md`
- `.ai-assisted-architecture/standards/standard-traceability.md`

## Phase 3: Create Artefacts

### Step 1: Create platforms/PL-NNN/index.md
Create the Platform folder and `index.md`. Use the next available identifier. Link to the parent Strategic Outcome folders.

## Phase 4: Self-Verification

Execute the **AI Agent Self-Verification Checklist** from `platform-standard.md`.
