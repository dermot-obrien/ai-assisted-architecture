# Foundation Capabilities

This folder contains seed capability content that can be copied into a workspace.

## Seed Sources

- `capability-model.md`: Seed capability taxonomy and narrative.
- `capability-hierarchy.csv`: Seed parent-child hierarchy (L1/L2/L3).
- `capability-abb-mapping.csv`: Seed L3-to-ABB mapping.
- `CAP-###/index.md`: Seed capability specifications by stable ID.

## Diagram Views

- `diagrams/l0/`: Optional enterprise-wide L0/L1 maps.
- `diagrams/l1/`: One capability map per L1 domain.
- `diagrams/traceability/`: Capability-to-ABB traceability views.

## Archive

- `archive/`: Historical/working diagram artefacts.

## Editing Rule

When this seed is used in a workspace, edit the workspace copy, not the framework copy.
