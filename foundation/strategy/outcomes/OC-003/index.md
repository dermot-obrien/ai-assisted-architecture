# OC-003 MTTD Reduction

| Property | Value |
| :--- | :--- |
| **Outcome ID** | `OC-003` |
| **Name** | Mean Time to Detect (MTTD) Reduction |
| **Measure** | MTTD for multi-service incidents < 5 minutes. |
| **Status** | `draft`|

## 1. Definition
Drastic reduction in the time taken to identify cross-boundary incidents.

## 2. Business Rationale
Minimizes impact of system failures and improves overall availability.
