# OC-005 Developer Self-Service Efficiency

| Property | Value |
| :--- | :--- |
| **Outcome ID** | `OC-005` |
| **Name** | Developer Self-Service Efficiency |
| **Measure** | 90% of standard infrastructure requests fulfilled without manual intervention within 15 minutes. |
| **Status** | `draft`|

## 1. Definition
Achieve a state where developers can provision, configure, and deploy standard workloads through self-service workflows without raising tickets or waiting for platform team intervention.

## 2. Business Rationale
Manual provisioning creates bottlenecks, increases lead time, and diverts platform engineering effort from strategic work to ticket-driven toil.
