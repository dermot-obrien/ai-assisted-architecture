# OC-006 Cloud Cost Efficiency

| Property | Value |
| :--- | :--- |
| **Outcome ID** | `OC-006` |
| **Name** | Cloud Cost Efficiency |
| **Measure** | Infrastructure unit cost per transaction decreases by 20% year-over-year with full cost attribution to owning teams. |
| **Status** | `draft`|

## 1. Definition
Achieve a state where every pound of cloud spend is attributed to an owning team, optimised against actual usage, and governed by automated budget controls.

## 2. Business Rationale
Unattributed cloud spend grows unchecked and creates budget surprises. Cost visibility and automated governance enable informed trade-offs between performance, reliability, and cost.
